# SugarTeddy

A colorful endless runner set in the whimsical world of Cotton Candy Land.

## About the Game

SugarTeddy is an endless runner where players control a Purple Bear racing through a sweet yet dangerous candy-themed world. Dodge blade-shaped obstacles, survive for as long as possible, and challenge yourself to achieve the highest score.

## Play the Game

https://clalalalala.itch.io/sugar-teddy

## Features

* Endless runner gameplay
* Colorful Cotton Candy Land environment
* Increasing challenge as you survive longer
* High-score focused experience
* Simple and intuitive controls

## Controls

| Action          | Key            |
| --------------- | -------------- |
| Move Up/left    |  W / Up Arrow  |
| Move Down/right | S / Down Arrow |

## How to Play

Avoid incoming obstacles and survive for as long as possible. The longer you stay alive, the higher your score becomes.
